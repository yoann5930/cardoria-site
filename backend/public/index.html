Un catalogue organisé par licences et extensions

Les pages CardoriaShop sont reliées entre elles pour permettre de passer rapidement d'une licence à une extension puis à la fiche détaillée d'une carte. Cette structure facilite la recherche de cartes Pokémon françaises, anglaises, japonaises ou coréennes lorsque ces versions sont présentes au catalogue.

Comment utiliser CardoriaShop pour une carte Pokémon ?

Commencez par ouvrir le catalogue Pokémon, sélectionnez l'extension correspondante puis la carte recherchée. La fiche réunit les principales informations disponibles : nom, numéro, rareté, extension, image et données de prix. Pour une carte que vous possédez, l'espace estimation permet ensuite d'obtenir une analyse complémentaire.
